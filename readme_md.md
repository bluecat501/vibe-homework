# ✨ 雙形態全息光柵翻轉卡 (Mythic Lenticular Hologram Card)

> 一個基於 Web 技術、純前端打造的 3D 體感光柵互動 Web App。透過手機陀螺儀或滑鼠視差，實現如同實體光柵閃卡般的雙形態平滑折射過渡。

---

## 📖 專案規格書 (Project Specification)

### 1. 設計靈感與概念
本專案靈感源自實體「3D 光柵變色卡（Lenticular Card）」。傳統卡片利用微稜鏡光柵結構，讓觀看者在不同角度看到不同畫面。本作品運用現代 Web 技術重現此視覺體驗，讓使用者在晃動或翻轉手機時，能即時看見兩種型態（如：月夜幽藍 / 晨曦金耀）的流動色散與視差交替。

### 2. 核心技術與功能
- **3D 空間姿態運算**：使用 CSS 3D Transforms (`rotateX`, `rotateY`, `perspective`) 營造真實立體卡片景深。
- **手機陀螺儀體感連動**：整合 HTML5 `DeviceOrientation API`，讀取手機傾斜姿態（$\gamma, \beta$ 角度）實現零延遲體感互動。
- **光柵交叉溶解 (Cross-Dissolve)**：將角度數值動態映射為不透明度權重，模擬實體光柵卡的光線折射切換。
- **動態全息彩虹流光 (Holographic Foil)**：疊加半透明動態彩虹漸層與垂直光柵紋理，增強實體雷射卡的立體閃卡質感。
- **本地自訂相片上傳**：內建 HTML5 `FileReader API`，支援使用者本地選取相片即時預覽，相片不上傳至外部伺服器，安全且隱私無虞。
- **9:16 自適應版型**：卡片固定為黃金 9:16 比例，適配主流手機桌布與直式藝術海報。

## 🛠️ 技術棧 (Tech Stack)

- **標記語言**：HTML5 (Canvas / Semantic Markup)
- **視覺樣式**：CSS3 (CSS Grid/Flexbox, 3D Transforms, Mix-blend-mode)
- **互動邏輯**：Vanilla JavaScript (ES6+, DeviceOrientation API, FileReader API)
- **部署平台**：GitHub Pages (靜態單頁面託管)

## 🚀 快速開始與使用方式

### 體驗方式
1. **手機體驗（推薦）**：
   - 使用手機瀏覽器開啟部署完成的 GitHub Pages 連結。
   - 點擊底部「啟用手機翻轉感應」按鈕授權陀螺儀。
   - 左右翻轉或傾斜手機，即可感受雙形態光柵切換。
2. **電腦體驗**：
   - 在螢幕上移動滑鼠游標，卡片視角與光影會隨滑鼠位置產生 3D 視差。
   - 亦可點擊底部「自動擺動展示」進入自動展示模式。
3. **自訂更換相片**：
   - 點擊頂部「更換形態 A」或「更換形態 B」按鈕。
   - 建議選擇比例為 **9:16** 的兩張直式相片（例如：1080×1920），以獲得最佳對齊效果。
